# СНТ «Кольчугино» ЗИМОЙ

Игра-шутка для соседей: игрок жмёт одну большую кнопку «УБРАТЬ СНЕГ», трактор пытается расчистить одну из девяти улиц, а правление чаще всего отвечает очередной отмазкой. Три игровых дня, 40 уникальных отмазок, после каждой ночи снег возвращается.

Все персонажи вымышлены.

## Как устроено

- Вся игра — один файл [`index.html`](index.html): HTML, CSS и JavaScript внутри.
- Никаких библиотек, сборки, шрифтов, картинок и звуков; графика — CSS и эмодзи.
- Работает офлайн и в любом современном браузере: Android, iPhone, планшеты, компьютеры.
- Баланс (шанс уборки, длина дня, скорость трактора, показ таймера) — в объекте `CFG` в начале скрипта.

## Локальный запуск

Откройте `index.html` двойным кликом — сервер не нужен.

## Публикация на GitHub Pages

Сборка не требуется: GitHub Pages раздаёт файлы из корня ветки `main` как есть. Все пути в игре относительные, поэтому она работает по адресу проекта `https://<пользователь>.github.io/<репозиторий>/`.

1. Отправьте изменения в ветку `main` на GitHub (`git push origin main`).
2. В репозитории на GitHub откройте **Settings → Pages**.
3. В блоке **Build and deployment** выберите **Source: Deploy from a branch**.
4. Выберите ветку **`main`** и папку **`/ (root)`**, нажмите **Save**.
5. Через 1–2 минуты игра откроется по адресу вида
   `https://anddr28.github.io/game-sntkolchugino/`
   (точная ссылка появится вверху страницы **Settings → Pages**).

Файл `.nojekyll` отключает обработку Jekyll: GitHub публикует файлы без изменений.

Каждый следующий `push` в `main` обновляет сайт автоматически.
